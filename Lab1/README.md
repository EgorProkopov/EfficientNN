## GPU
Код выполнялся на Colab, GPU - T4.

## Воспроизведение результатов
Результаты воспроизводятся в google colab на T4 последовательным выполнением ячеек кода.

Характеристики GPU взяты следующие:
- 8,1 TFLOP/s скорость вычислений
- 320 Гб/c пропускная способность памяти
- 70Вт мощности

mfu для расчёт времени взято как 0.5.

## Результат
Подсчёт FLOPs совпал с профилировщиком.
Подсчёт памяти не совпал. Скорее всего, потому что в вычислениях не учитываются временные буферы.
