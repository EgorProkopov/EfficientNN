## Сборка из директории Lab2/

```sh
latexmk -cd -xelatex -interaction=nonstopmode -halt-on-error report/presentation/presentation.tex
```

Результат: `report/presentation/presentation.pdf`. Ключ `-cd` переключает сборку в директорию исходника. Для последующих сборок достаточно той же команды.

Нужны XeLaTeX, latexmk, пакеты Beamer, fontspec, polyglossia, pgfplots и шрифт Arial. На компьютере пользователя они проверены, презентация собрана XeLaTeX. pdfLaTeX для этого исходника не подходит. При сборке на системе без Arial замените четыре объявления шрифтов в преамбуле на доступный шрифт с кириллицей.

## Источники и изменения обозначений

- Структура и основное содержание: `/Users/egorprokopov/Downloads/Sparse Attention as Compact Kernel Regression.pdf` — пользовательский конспект.
- Проверка формул и экспериментальных чисел: [Santos et al., Sparse Attention as Compact Kernel Regression, arXiv:2601.22766v3](https://arxiv.org/pdf/2601.22766v3).
- Числовые примеры sparsemax и степени r рассчитаны для пояснения; это не результаты экспериментов.

В конспекте компактное ядро записано со знаменателями как `2h²`, так и `h²`. В презентации везде используется `κ_h=[1−d²/h²]_+`, так что `h` — радиус отсечения. У гауссовского ядра ширина обозначена `σ`, чтобы не смешивать эти параметры.

В формуле ReLUmax параметр `h` задаёт масштаб порога, а допустимый разрыв в сходстве равен `bh²`; это обозначение сохранено из конспекта.

У адаптивного радиуса уточнено: сумма преобразованных выражений `[s_i/γ−τ]_+` равна 1, а сумма исходных значений ядра не обязана быть 1. Таблицы содержат только выбранные в конспекте методы. Для RegBench указано, что 1k и 40k — количество обучающих примеров. Для синтетических задач приведены средние по трём запускам, без максимумов из верхних индексов оригинала.
